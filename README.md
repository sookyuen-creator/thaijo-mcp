# ThaiJO / TCI MCP Connector

ตัวเชื่อม (MCP Server) ที่ให้ Claude ค้นและดึงข้อมูลบทความวิชาการไทยจาก **ThaiJO** ซึ่งเป็นระบบที่วารสารในฐาน **TCI** ใช้เผยแพร่บทความ โดยใช้ช่องทาง OAI-PMH อย่างเป็นทางการของ ThaiJO (https://www.tci-thaijo.org/public/oai.html)

## ความสามารถ (Tools)

| Tool | ใช้ทำอะไร |
|---|---|
| `thaijo_list_servers` | ดูรหัสเซิร์ฟเวอร์ ThaiJO แยกตามกลุ่มสาขา (SC, LI, PH, HE, SO) |
| `thaijo_list_journals` | ดูรายชื่อวารสารในเซิร์ฟเวอร์ พร้อม journal path (กรองชื่อได้) |
| `thaijo_list_articles` | ดึงบทความทั้งวารสารทีละหน้า (~100 บทความ/หน้า) สำหรับ systematic review |
| `thaijo_search_articles` | ค้นตามคำสำคัญในชื่อเรื่อง คำสำคัญ และบทคัดย่อ (ไทย/อังกฤษ) กรองปีได้ |
| `thaijo_get_article` | ดึงข้อมูลบทความเดียวแบบเต็ม (บทคัดย่อไทย+อังกฤษ, DOI, ลิงก์) |
| `thaijo_check_tci_tier` | ตรวจว่าวารสารอยู่ TCI กลุ่ม 1, 2 หรือ 3 พร้อมระดับความเชื่อมั่นและหลักฐาน |

นอกจากนี้ `thaijo_search_articles` รับพารามิเตอร์ `tci_tiers` เช่น `[1]` เพื่อกรองเฉพาะบทความจากวารสาร TCI กลุ่ม 1 ได้ในคำสั่งเดียว

ข้อมูลที่ได้ต่อบทความ: ชื่อเรื่องไทย/อังกฤษ ผู้แต่ง คำสำคัญ บทคัดย่อ ปี แหล่งตีพิมพ์ (ปีที่/ฉบับที่) URL และ DOI

## ข้อจำกัดที่ควรทราบ

ThaiJO อนุญาตให้ดึงข้อมูลได้ **10 ครั้งต่อนาทีต่อ IP** ตัวเชื่อมนี้จึงเว้นจังหวะให้อัตโนมัติ (ครั้งละ 6.5 วินาที) และเก็บ cache ไว้ 6 ชั่วโมง การค้น 1 หน้าใช้เวลาประมาณ 7 วินาที ดังนั้นควรระบุวารสารทุกครั้งที่ค้น

OAI-PMH ไม่มีระบบค้นหาในตัว การค้นจึงเป็นการสแกนบทความทีละหน้าแล้วกรองด้วยคำสำคัญ ถ้าวารสารมีบทความมาก ผลลัพธ์จะคืน resumption token ให้ค้นต่อ

ระบบดึงได้เฉพาะเมทาดาทา (ไม่ใช่ PDF ฉบับเต็ม)

## การตรวจกลุ่ม TCI ทำงานอย่างไร

ศูนย์ TCI ไม่มี API สาธารณะ เครื่องมือจึงตรวจ 2 ชั้นตามลำดับ

**ชั้นที่ 1 รายชื่ออ้างอิง** อ่านจากไฟล์ `tci_tiers.csv` หรือจาก Google Sheet ของอาจารย์ (แนะนำ) ถ้าคอลัมน์ `source` เป็น `official_tci_list` จะได้ความเชื่อมั่น "สูง" ไฟล์ตั้งต้นมีวารสารตัวอย่าง 5 รายการที่ตรวจจากประกาศของวารสารแล้ว

**ชั้นที่ 2 ประกาศบนหน้าเว็บวารสาร** ถ้าไม่พบในรายชื่อ ระบบจะอ่านหน้าแรกและหน้า About ของวารสารใน ThaiJO เพื่อหาข้อความ "TCI กลุ่มที่ 1 / Tier 1" ถ้ามีปีรอบปัจจุบัน (2568–2572 / 2025–2029) กำกับ ได้ความเชื่อมั่น "ปานกลาง" ถ้าไม่มีปีกำกับได้ "ต่ำ" เพราะอาจเป็นข้อมูลรอบเก่า ผลการตรวจเก็บ cache ไว้ 7 วัน

> สำหรับงานยื่นขอตำแหน่งทางวิชาการ ควรยืนยันกลุ่มที่ tci-thailand.org ทุกครั้งที่ผลไม่ใช่ความเชื่อมั่น "สูง"

### ตั้งค่า Google Sheet เป็นรายชื่ออ้างอิง (แนะนำ)

1. สร้าง Google Sheet ใหม่ แถวแรกใส่หัวคอลัมน์ตามไฟล์ `tci_tiers.csv` คือ `journal_name, journal_name_en, issn_print, issn_online, tier, round, valid_from, valid_to, thaijo_url, source, note`
2. ใส่รายชื่อวารสารจากประกาศผลการประเมินของศูนย์ TCI (ใส่ `source` เป็น `official_tci_list`) คอลัมน์ที่จำเป็นคือ `tier` และอย่างน้อยหนึ่งใน `thaijo_url`, ISSN หรือชื่อวารสาร
3. เมนู File → Share → Publish to web เลือกแผ่นงาน และรูปแบบ CSV แล้วคัดลอกลิงก์
4. ใน Render ไปที่บริการ thaijo-mcp → Environment ใส่ค่า `TCI_TIERS_URL` เป็นลิงก์นั้น แล้วกด Save (ระบบรีสตาร์ตเอง)

หลังจากนั้นอาจารย์แก้ข้อมูลใน Sheet ได้ตลอด ระบบโหลดใหม่ทุก 24 ชั่วโมง หรือสั่ง Claude ว่า "ตรวจกลุ่ม TCI ... แบบ refresh_list" เพื่อโหลดทันที

## ขั้นตอนติดตั้ง (Render.com ฟรี ประมาณ 15 นาที)

1. **สร้าง GitHub repository** สมัคร github.com (ถ้ายังไม่มี) กด New repository ตั้งชื่อ เช่น `thaijo-mcp` แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`server.py`, `tci_tier.py`, `tci_tiers.csv`, `requirements.txt`, `render.yaml`, `Dockerfile`, `README.md`) โดยลากวางในหน้า "uploading an existing file" ของ GitHub ได้เลย ไม่ต้องใช้คำสั่ง git

2. **Deploy บน Render** สมัคร render.com ด้วยบัญชี GitHub กด New → Blueprint เลือก repository `thaijo-mcp` แล้วกด Apply ระบบจะอ่าน `render.yaml` และติดตั้งให้เอง (เลือก region Singapore ให้แล้ว) รอจนสถานะเป็น Live แล้วคัดลอก URL เช่น `https://thaijo-mcp.onrender.com`

3. **เพิ่มเป็น Connector ใน Claude** เปิด Claude ไปที่ Settings → Connectors → Add custom connector ตั้งชื่อ `ThaiJO` และใส่ URL โดยต่อท้ายด้วย `/mcp`

   ```
   https://thaijo-mcp.onrender.com/mcp
   ```

   (สำหรับแผน Team/Enterprise ผู้ดูแลองค์กรอาจต้องเป็นผู้เพิ่ม connector)

4. **เปิดใช้งานในแชต** กดปุ่มเครื่องมือในช่องพิมพ์ แล้วเปิด ThaiJO

> หมายเหตุ: แผนฟรีของ Render จะ "หลับ" เมื่อไม่มีการใช้งาน 15 นาที การเรียกครั้งแรกหลังหลับอาจใช้เวลา 30–60 วินาที หากต้องการให้ตอบไวตลอดเวลา อัปเกรดเป็นแผน Starter ($7/เดือน)

## การทดสอบบนเครื่อง (ไม่บังคับ)

```bash
pip install -r requirements.txt
python test_offline.py          # ทดสอบการดึง/ค้นบทความด้วยข้อมูลจำลอง
python test_tier.py             # ทดสอบการตรวจกลุ่ม TCI ด้วยข้อมูลจำลอง
python server.py                # รันเซิร์ฟเวอร์ที่ http://localhost:8000/mcp
npx @modelcontextprotocol/inspector   # ทดสอบเรียก tool จริง
```

## ตั้งค่าเพิ่มเติม (Environment Variables)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `THAIJO_MIN_INTERVAL` | `6.5` | วินาทีขั้นต่ำระหว่างการเรียก ThaiJO (ไม่ควรต่ำกว่า 6) |
| `THAIJO_CACHE_TTL` | `21600` | อายุ cache (วินาที) |
| `TCI_TIERS_URL` | (ว่าง) | ลิงก์ Google Sheet ที่เผยแพร่เป็น CSV สำหรับรายชื่อกลุ่ม TCI |
| `PORT` | `8000` | พอร์ต (Render กำหนดให้อัตโนมัติ) |

## ความปลอดภัย

เซิร์ฟเวอร์นี้อ่านอย่างเดียว ไม่เก็บข้อมูลผู้ใช้ และเรียกเฉพาะ OAI endpoint และหน้าเว็บสาธารณะของ ThaiJO (รวมถึง Google Sheet ที่อาจารย์ตั้งไว้) URL ของ connector เป็นสาธารณะ ผู้ที่รู้ URL สามารถเรียกใช้ได้ ซึ่งจะใช้โควตา 10 ครั้ง/นาทีร่วมกัน จึงไม่ควรเผยแพร่ URL
